# astrbot_plugin_keyword_api_failover

当原模型返回内容里命中指定错误关键词时，本插件会丢弃该回复，转而调用你在 AstrBot 中已经配置好的备用 LLM 提供商，并把备用提供商的结果作为最终回复发给用户。

## 功能说明

- 命中错误关键词后自动切换到备用 LLM 提供商
- **多提供商按顺序轮换**：如果某个备用模型的回复仍命中关键词或调用失败（包括返回空文本、Provider 不存在等），自动继续尝试下一个提供商，直到拿到干净回复或全部耗尽
- 备用模型直接从 AstrBot 已配置的提供商中选择，不需要在插件里重复填写 API 地址、API Key 或模型名
- 通过 AstrBot 的 LLM 调用接口处理请求，可复用 AstrBot 对文本、多模态等能力的适配
- 尽量复用原始会话中的 `system_prompt`、`contexts`、当前 `prompt` 和图片输入

## 推荐配置

- `error_keywords`：需要触发切换的关键词，每行一个，匹配时不区分大小写
- `provider_id`（第一备用 LLM 提供商）：命中关键词后优先调用的提供商；在插件配置页中点击"选择提供商..."下拉选择。留空则使用当前会话正在使用的提供商。
- `provider_ids`（后续备用列表）：每行填一个 Provider ID 或模型名。当第一备用也命中关键词或失败时，按顺序依次尝试此列表。留空则只用第一备用。
- `fallback_reply`：所有备用提供商均失败或回复仍含关键词时，返回给用户的兜底内容
- `forward_images`：是否向备用提供商转发图片。只有备用提供商明确支持多模态/图片输入时才开启；默认关闭以避免不支持图片的 OpenAI 兼容接口报 400。

### Provider ID 与模型名

`llm_generate` 接口需要的是**提供商 ID**（即你在服务商配置页为该提供商起的名称，可在"选择提供商..."弹窗中查看），不是模型名。

为了方便填写，`provider_ids` 文本框支持直接填模型名，插件会自动解析：

1. 精确匹配 Provider ID
2. 忽略大小写匹配 Provider ID
3. 按提供商当前的模型名匹配
4. 匹配 `xxx/yyy` 形式的后半段

多个提供商用同一个模型时只会命中第一个，需要精确控制请填真实 Provider ID。解析失败时日志会打印当前所有可用的 Provider ID 及对应模型，方便对照。

## 使用建议

先在 AstrBot 的服务商/LLM 配置中添加并测试好备用模型。然后进入本插件配置，选择第一备用提供商，需要更强容错就把其他候选填入 `provider_ids` 列表，并把你想拦截的错误回复关键词填入 `error_keywords`。
